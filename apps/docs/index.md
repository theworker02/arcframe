# Arcframe

**The engineering control plane for Cursor.**

Local-first repository intelligence for AI coding agents: Arc Index, Arc Graph, budgeted context packs, memory, blast-radius impact analysis, and a precise Cursor MCP server — without uploading source to Arcframe servers.

## Principles

- Local-first developer tools (analysis stays under `.arcframe/`)
- Evidence over assumptions (Confirmed / Strongly inferred / Weakly inferred / Unknown)
- Incremental analysis
- One engine shared by CLI, MCP, Cursor UI, and flows
- Safe automation (reads automatic; destructive ops need explicit intent)
